One original satirical sentence (141 characters) roasting lawmakers who
would write the rules for AI, crypto and the internet but cannot convert a
file to PDF, written for the [The Long Roast: Lawmakers and the File They
Cannot Convert](https://make.fun/bounty/u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7)
bounty on [make.fun](https://make.fun).

## The line

> The lawmakers who will write the rules for AI, crypto, and the entire internet still summon an intern to turn their Word document into a PDF.

## How it works

`main.ts` (Node 22) writes the line to `/output/entry.txt` — one sentence,
141 characters, UTF-8, no trailing newline. No input, no network, no
dependencies.

## Run

```sh
node main.ts
cat /output/entry.txt
```
